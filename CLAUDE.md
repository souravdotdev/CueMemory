## Agent skills

### Issue tracker

Issues and specs live in GitHub Issues (souravdotdev/Resonory), managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Uses the five default labels: needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix. See `docs/agents/triage-labels.md`.

### Domain docs

Multi-context: a root `GLOSSARY-MAP.md` points to a `GLOSSARY.md` per context under `docs/contexts`. See `docs/agents/domain.md`.
